# worm-print-platform 使用文档

把 worm-print-platform 当作**打印能力**接入你的项目，或**开发/安装插件**、**自定义界面语言**——这套文档按角色与任务组织，也可从头到尾线性阅读。

> 适用范围：当前稳定主线 **1.6.6**（`core` / `canvas` / `plugin-kit` 同号同批发版）。
> 术语：正文以中文为主，命令、包名、字段名、路径、代码保留原文；关键概念首次出现给中英对照。

## 1. 按角色/任务选路径

| 你是 | 要做的事 | 从哪开始 |
| --- | --- | --- |
| **宿主接入者** | 把设计器 + 打印接进 Vue 3 / Vue 2 / React / jQuery 项目 | [01 开始之前](./01-getting-started.md) → 对应框架篇（02/03/04/05）→ [09 排错](./09-migration-faq.md) |
| **插件使用者** | 安装现成插件（如 echarts）并让设计器加载 | [07 插件安装与配置](./07-plugin-install.md) |
| **插件开发者** | 从零开发并发布自定义插件 | [08 插件开发](./08-plugin-dev.md)（前置 [01](./01-getting-started.md)、[07](./07-plugin-install.md)）；索引格式与命名见 [插件市场规范](../plugin-market-spec.md) |
| **多语言定制者** | 生成/校验/接入自定义语言包 | [06 多语言配置与自定义](./06-i18n.md) |
| **AI Agent** | 让 AI 按规范完成上述任务 | 先读 [AGENTS.md](./AGENTS.md)，再按其中任务路线取用文档 |

## 3. 每篇的统一结构

除附录类文档外，每篇核心章节都按 `前置条件 → 步骤 → 验证 → 排错 →（可选）AI 提示词` 组织；代码块会标注执行目录（`cwd`）与预期结果。照着做时请按顺序执行“验证”，它决定你是否真的完成。

## 4. AI Agent 接入

AI 编程工具请先读 [AGENTS.md](./AGENTS.md)：它给出文档地图、三条任务路线、权威源与执行约束，避免凭记忆臆测 API。技能的 npx 安装与提示词模板见 [01 开始之前](./01-getting-started.md)。
